从部署到日常使用，每一个设计决定都指向同一件事：让机器人稳定运行，同时不占用你的机器与注意力。

单文件核心

主程序只有一个 Python 文件，配合 start.sh 一条命令完成虚拟环境、依赖安装与服务注册。没有数据库、没有消息队列、没有编译步骤。

aiohttpsystemd / 后台Python 3.6+

多机器人并行，按来源回复

最多 20 个 QQ 官方机器人并行在线，每个 AppID 一条独立连接。消息携带来源连接，回复只会回到它来的那一条，多账号同时运营不会串台。

快速开始

三步，跑起来

只需要 Python 3.6 或更高版本。脚本会自动创建虚拟环境、安装依赖、生成配置并注册服务。

1

解压部署包

从下载页获取源码包，解压到任意目录，不需要预先安装任何 Python 依赖。

2

执行 start.sh

同意免责声明后自动建 .venv、安装 aiohttp、生成 30 位访问令牌；有 systemd 时注册为服务，否则后台运行。

3

打开控制台

访问 http://127.0.0.1:6199，用 ./start.sh token 查看到的令牌登录，再配置模型与平台。

常见问题

开始之前，你可能想知道

运行 YueWuBot 需要什么环境？

Python 3.6 或更高版本即可，aiohttp 由 start.sh 自动安装到项目内的虚拟环境。不需要数据库、Node.js、Redis 或任何常驻的后端服务。Linux 上有 systemd 时会自动注册服务，其他环境以后台进程方式运行。

支持哪些 QQ 平台？

开源版只接 QQ 官方机器人，在控制台填 AppID 与 AppSecret 即可。需要接 SnowLuma、NapCat 这类 OneBot v11 / v12 实现，或接微信官方机器人，用完整版。

控制台令牌在哪里？

首次启动自动生成 30 位字母数字混合令牌，写入配置与 data/TOKEN.txt。执行 ./start.sh token 查看，./start.sh token --reset 重置；令牌不随包分发，每台机器都不一样。

插件要怎么写、怎么装？

把一个 main.py 和一个 m.json 放进 zip 根目录，可选 icon.png，其他资源统一放入 assets/。在控制台「插件」页上传即生效，也可用启停、配置与删除功能管理。完整字段与钩子说明见开发文档。

这个官网会收集数据或提供在线服务吗？

不会。本站是纯静态页面，由 GitHub Pages 直接托管，没有后端、没有数据库、没有登录、没有统计脚本，也不发起任何接口请求。页面上的控制台内容均为截图展示；真正可交互的控制台运行在你自己部署的机器人进程中。

可以商用或二次开发吗？

开源版可以。它以 MIT 许可证发布，允许自由使用、修改与分发，只需保留版权与许可声明；完整版源码私有，仅按约定分发。第三方依赖信息见仓库内的 LICENSE 与 THIRD-PARTY 说明。
