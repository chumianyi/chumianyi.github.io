部署要求

只需 Python 与一个模型接口，不需要 Docker、数据库或额外服务。

Python 3.6+

核心程序依赖 aiohttp，由安装脚本自动装入项目内虚拟环境，不污染系统环境。

唯一运行时依赖

模型 API Key

在控制台「模型」页填写任何 OpenAI 兼容接口的地址与密钥，配置即生效，无需改代码。

登录后配置

无需 Docker

单进程运行，常驻内存约 40 MB；QQ 官方机器人只需在开放平台创建应用并加入群。

零额外服务
终端 · 三步启动
unzip YueWuBot-1.4.2-QQ.zip && cd YueWuBot-1.4.2-QQ
./start.sh          阅读免责声明后输入 Y 或 yes 同意，自动装依赖并生成令牌
./start.sh token    查看 30 位令牌，登录 http://127.0.0.1:6199

部署完成后，日常启动只用这一条
./已部署后启动.sh

完整参数、systemd 管理与环境变量说明见 开发文档 · 安装与运行。

依赖源与多架构支持

安装脚本按固定顺序尝试三个依赖源，任一成功即继续，无需手动干预。

1 · 本站托管包

https://chumianyi.github.io/pip/ 提供按架构预编译的 wheel 与平台无关通用包，离线友好。

默认首选

2 · 中科大源

首选源不可用或架构未命中时自动切换，覆盖更多 Python 版本。

自动降级

3 · 清华源

最后一级备用，前两级均失败时兜底，保证依赖可安装。

最终兜底
架构覆盖：托管包含 x86_64 / X64 / x86-x64 / AMD64、ARM64 / aarch64、X86 / i686 的 Python 3.6 预编译 wheel，另附平台无关的源码包与纯 Python wheel，可覆盖其他架构与更高的 Python 版本。详见 托管包索引。
