YueWuBot pip packages

Static wheelhouse hosted on GitHub Pages. YueWuBot start.sh tries this source first, then falls back to USTC, then TUNA.

Packages cover x86_64 / X64 / x86-x64 / AMD64, ARM64 / aarch64, X86 / i686, plus universal source distributions and pure-Python wheels for any other platform.
